# C1 : LockyClient

## Descrição

O LockyClient é o frontend web desenvolvido para a LockyAPI (M1). A aplicação imita a parte de cliente de um sistema de cacifos públicos, no estilo dos cacifos Locky que se encontram em estações e centros comerciais em Portugal.

Qualquer pessoa que abra o site pode consultar a lista de estações disponíveis e, em cada estação, ver quais os cacifos existentes, o tamanho de cada um e o preço por hora. Para reservar é preciso fazer login com a conta GitHub. A partir daí, o utilizador tem acesso ao dashboard com as suas reservas e pode criar reservas novas, editar as datas de reservas existentes ou cancelá-las.

A aplicação também tem uma área de gestão (`/manage/stations` e `/manage/lockers`) para criar, editar e remover estações e cacifos. Como a API herdada do M1 não distingue utilizadores comuns de administradores, esta área está apenas protegida por autenticação - qualquer utilizador logado tem acesso. Esta limitação está documentada no capítulo 3.

O front comunica com a API por HTTP. Em desenvolvimento o frontend corre no Vite na porta 5173 e a API numa porta separada (3001). Em produção, um servidor Nginx serve os ficheiros estáticos da build e faz proxy dos pedidos para o container da API, dando a aparência ao browser de que tudo vem do mesmo sítio.
